# TOURFORU Ride

관광코스를 선택하면 탑승 인원과 짐 수량에 맞는 차량과 가이드기사를 추천하고 예약·결제까지 연결하는 관광 이동 매칭 서비스입니다.

## MVP 흐름

1. 관광코스 검색
2. 이순신 승전길 선택
3. 이순신 승전길 트래킹 세부코스 선택
4. 코스 상세정보 및 확정
5. 탑승 인원 / 짐 수량 입력
6. 차량 + 가이드기사 추천
7. 기사 이력 / 차량 정비이력 확인
8. 예상 총 소요시간 및 가격 확인
9. 예약 내용 최종 확인
10. 토스페이먼츠 테스트 결제
11. 결제 후 기사 안심번호 제공

## 반응형

- Mobile: 360px+
- Tablet: 768px+
- Desktop: 1200px+
